# Libraries Used in PetWise Project

This document lists the libraries and frameworks utilized in the PetWise project, along with their respective versions.

## Backend Libraries

- **Flask**: A lightweight WSGI web application framework for Python.
  - Version: 2.0.1

- **Flask-Cors**: A Flask extension for handling Cross-Origin Resource Sharing (CORS).
  - Version: 3.0.10

- **Flask-RESTful**: An extension for Flask that adds support for quickly building REST APIs.
  - Version: 0.3.9

- **SQLAlchemy**: The Python SQL toolkit and Object-Relational Mapping (ORM) system.
  - Version: 1.4.22

## Frontend Libraries

- **React**: A JavaScript library for building user interfaces.
  - Version: 17.0.2

- **React Router**: A collection of navigational components that compose declaratively with your application.
  - Version: 5.2.0

- **Axios**: A promise-based HTTP client for the browser and Node.js.
  - Version: 0.21.1

- **Bootstrap**: A front-end framework for developing responsive and mobile-first websites.
  - Version: 5.1.3

## Development Tools

- **Node.js**: JavaScript runtime built on Chrome's V8 JavaScript engine.
  - Version: 14.17.0

- **npm**: Package manager for JavaScript, included with Node.js.
  - Version: 6.14.13

## Testing Libraries

- **Jest**: A delightful JavaScript testing framework with a focus on simplicity.
  - Version: 27.0.6

- **React Testing Library**: A lightweight solution for testing React components.
  - Version: 11.2.7

This list may be updated as new libraries are added or existing ones are upgraded.
